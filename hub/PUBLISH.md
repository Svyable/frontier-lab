# Publish to Hugging Face

Checklist before any Hub upload:

1. [ ] License chosen and stated
2. [ ] Training data / distillation sources credited
3. [ ] Eval numbers reproducible or clearly caveated
4. [ ] Model / dataset / Space card filled (no empty “Coming soon” dumps)
5. [ ] Link back to the matching `experiments/` or `writeups/` path in this repo
6. [ ] Human OK for anything branded as Svyable org publish

Preferred artifact types:

- **Model** — weights + card + eval snippet
- **Dataset** — probe sets, curricula samples (license-clean only)
- **Space** — tiny demo of a probe or generation sample
- **Paper page** — when a writeup is ready to claim as a paper

Record Hub URLs under `hub/artifacts.md` after publish.
